View your app in AI Studio: https://ai.studio/apps/ded47315-b55b-4a05-888d-b501bd92b872

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
